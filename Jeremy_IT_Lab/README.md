#  Jeremy's IT Lab - Completed Labs & Notes

Welcome to the practical implementation section of my CCNA repository. This directory showcases my hands-on configurations and personal study notes based on the excellent [Jeremy's IT Lab CCNA Course](https://youtube.com/playlist?list=PLxbwE86jKRgMpuZuLBivzlM8s2Dk5lXBQ&si=Wcgd6YBVWGQ7YcgO) on YouTube. 

To respect copyright, I do not distribute the original course files or Anki decks here. Instead, you will find my completed lab exercises and personal summaries.

## 📂 Contents

*   **[Packet_Tracer_Labs](./Packet_Tracer_Labs/)**: Contains my completed Cisco Packet Tracer files (`.pkt`). These are hands-on lab exercises I configured from scratch to practice routing, switching, VLANs, OSPF, and other core CCNA concepts. 
*   **[Study_Notes](./Study_Notes/)**: *(Optional)* My personal markdown notes summarizing key concepts, common IOS commands, and flashcard takeaways for active recall.

##  How to Use
1. **Explore the Configurations**: Open the `.pkt` files in **Cisco Packet Tracer** to review my network topologies and CLI configurations on various routers and switches.
2. **Review the Notes**: Check out the markdown notes for quick command references and troubleshooting tips.
