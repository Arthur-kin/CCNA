# 🌐 CCNA 200-301 Study Notes & Labs

Welcome to my CCNA (Cisco Certified Network Associate) learning repository! This project documents my journey to mastering network fundamentals, routing and switching technologies, and hands-on configurations. 

To keep things organized and easy to navigate, I have structured my learning resources into two main sections: theory/notes and practical labs.

## 📂 Repository Structure

### 1. 🤖 [AI_tutorial](./AI_tutorial)
This section contains my AI-assisted study notes and conceptual breakdowns.
*   **Comprehensive Notes:** Detailed explanations of core networking protocols (e.g., VLANs, STP, OSPF, NAT).
*   **Command References:** Useful Cisco IOS commands and troubleshooting techniques.
*   **Configuration Guides:** Step-by-step logic for setting up various network topologies.

### 2. 🛠️ [Jeremy_IT_Lab](./Jeremy_IT_Lab)
This section is dedicated to my hands-on practice, inspired by the fantastic [Jeremy's IT Lab CCNA Course](https://youtube.com/playlist?list=PLxbwE86jKRgMpuZuLBivzlM8s2Dk5lXBQ&si=Wcgd6YBVWGQ7YcgO). 
*   **Packet Tracer Labs (`.pkt`):** My completed lab files, configured from scratch to verify routing and switching concepts.
*   **Study Notes:** Personal takeaways and active recall summaries (Note: Original course files and Anki decks are not distributed here to respect copyright).
