#  Jeremy's IT Lab - Resources & Labs

Welcome to the practical implementation and review section of my CCNA repository. This directory contains resources based on Jeremy's IT Lab course materials, structured for active recall and hands-on practice.

## 📂 Contents

*   **[Anki_Decks](./Anki_Decks/)**: Flashcard files (`.apkg`) for daily review, helping reinforce core networking concepts, terminology, and IOS commands through spaced repetition.
*   **[Packet_Tracer_Labs](./Packet_Tracer_Labs/)**: Cisco Packet Tracer practice files (`.pkt`) covering structured network configuration topologies and labs.

##  How to Use
1. Import the `.apkg` files into **Anki** to practice active recall and memorize crucial CCNA concepts and command syntaxes.
2. Open the `.pkt` files in **Cisco Packet Tracer** to complete the hands-on lab exercises and verify configurations.
